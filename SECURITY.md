# Security Policy

OpenStandby reads notifications and calendar events, so privacy bugs are taken seriously.

Please **do not** open a public issue for security or privacy problems. Instead, use GitHub's
*Report a vulnerability* button under the repository's **Security** tab. You should get a reply within a week.

Things we especially want to hear about:

- Notification or calendar content becoming visible when it shouldn't (for example "Show message content" is off)
- Any code path that writes notification/calendar data to disk or logs
- Any way the app could reach the network
