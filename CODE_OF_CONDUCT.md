# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be welcoming, patient and respectful, whatever someone's background or experience level.
- Give and accept constructive feedback gracefully. Critique code, not people.
- No harassment, insults, trolling, sexualised language, or publishing others' private information.

## Enforcement

Report unacceptable behaviour privately to the maintainer via a GitHub direct contact or by opening a confidential security advisory on the repository.
Maintainers will review every report and may remove comments, commits, or contributors that violate this code.
